# 救急活動記録

救急隊向けの活動記録アプリの画面試作です。HTML・CSS・JavaScriptをそれぞれ独立したファイルに分けています。

## 起動方法

`index.html`をブラウザーで開いてください。ローカルサーバーを使う場合は、リポジトリのルートで `python3 -m http.server` を実行し、表示されたローカルURLにアクセスします。

## 主な機能

- 傷病者の基本情報の入力と自動保存
- 活動時間の計測
- バイタルと活動メモの追加・削除
- 引き継ぎチェック項目の記録
- 入力内容をブラウザーのローカルストレージに保存

## 試作版の注意

訓練・画面確認専用です。実際の救急活動、医療上の判断、個人情報の記録には使用しないでください。データは利用中のブラウザー内にのみ保存され、端末間の共有・バックアップ・認証・暗号化はありません。実運用には、所属機関の要件やセキュリティ・プライバシー・医療安全の審査が必要です。
