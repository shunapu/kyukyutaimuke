# 病院情報検索

救急隊向けに病院情報を探す画面の試作です。HTML・CSS・JavaScriptをそれぞれ独立したファイルに分けています。

## 起動方法

`index.html`をブラウザーで開いてください。ローカルサーバーを使う場合は、リポジトリのルートで `python3 -m http.server` を実行し、表示されたローカルURLにアクセスします。

## 試作機能

- 病院名・地域・診療科・設備情報のキーワード検索
- 地域・診療科での絞り込みと並び替え
- 施設の診療科、設備、住所などのサンプル表示
- スマートフォンでも使いやすい画面

## サンプル情報と実運用について

画面内の施設名・住所・診療科・設備はすべて架空のサンプルで、実在の施設情報ではありません。救急受入状況はこの試作から確認できず、「要電話確認」と表示します。

実際の施設情報を使うには、対象地域を決め、自治体・医療機関など信頼できる情報源と利用許諾・更新方法を確認した上で、データを差し替える必要があります。受入可否は変動するため、実運用では関係機関への確認手段を別途設けてください。
