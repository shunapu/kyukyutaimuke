# 救急隊支援

救急隊向けに、病院情報の登録・検索と、救急行動基準・マニュアル・プロトコールPDFの端末内管理ができる画面です。HTML・CSS・JavaScriptを別ファイルに分けています。

## 起動方法

`index.html`をブラウザーで開いてください。ローカルサーバーを使う場合は、リポジトリのルートで `python3 -m http.server` を実行し、表示されたローカルURLにアクセスします。

## 使い方

1. 「病院情報」ページのフォームに施設名、診療時間、診療科、設備などを入力します。地域、住所、電話番号は取り扱いません。
2. 「施設情報を追加」を押すと、施設カードが一覧に表示されます。診療科や設備は「、」またはカンマで区切って入力します。
3. 一覧の「編集」「削除」から登録内容を管理できます。キーワードや診療科で検索・絞り込みもできます。
4. 「救急マニュアル」ページでは、所属機関が承認した最新版のPDFを分類・改訂情報とともに登録し、閲覧・削除できます。1ファイル50MBまでです。

## 保存と注意事項

登録情報はブラウザーのローカルストレージに保存されます。同じブラウザー・端末でのみ利用でき、別端末との共有、バックアップ、ユーザー認証、暗号化はありません。ブラウザーのデータ消去で登録内容も消えます。共有利用や実運用には、サーバー、アクセス制御、バックアップ、適切なデータ管理と公式情報の更新手順が別途必要です。

施設情報は入力者が管理してください。アプリは情報の正確性や最新性を保証せず、救急受入状況も表示しません。実際の受入可否は必ず関係機関へ確認してください。旧形式で保存済みの地域・住所・電話番号は、病院情報を読み込んだ際に保存領域から削除します。

救急マニュアルのPDFはブラウザーのIndexedDBに保存され、病院情報とは別の保存領域を使います。資料保管用であり、アプリ自体は救急行動基準や医療上の指示を提供しません。登録する資料が所属機関の承認した最新版であることを確認し、実際の活動では所属機関の規定・指示に従ってください。
